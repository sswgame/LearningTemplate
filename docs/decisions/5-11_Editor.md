# 5-11. 에디터와 외부 공개

> 질문: 5-11. 에디터와 외부 공개 영역에서 이미 정한 것은 무엇이고 근거는 무엇인가?
> 독자: 같은 제안을 다시 하려는 사람, 정한 이유를 찾는 사람.
> 결론: 결정 기록 5 절의 한 영역이다. 번호 체계와 쓰는 법은 [결정 기록](../09_Decisions.md) 5절에 있다.

- **에디터 시나리오는 경계 전후 값을 이름으로 기억해 견준다(`Remember` · `sameAs` · `differsFrom`) — 단언마다 기대값을 손으로 적지 않는다**(2026-10-15, `AutomationRunner`). 시나리오는 데이터라 변수가 없어(언리얼 Functional Test · 유니티 Editor Test 는 변수로 듦) 기억한 값을 글 그대로 견주며 64 비트 상태 해시(`Editor.StateHash`)까지 정확히 견준다. 실행기가 엔진에 있어 플레이 · 모듈 리로드 · 백엔드 교체를 넘어 기억한다.
- **에디터 인스턴스를 다시 만들 때 선택 · 미저장 표시는 엔진 서비스(`EditSessionState`)에 맡겨 넘기고 되돌리기 스택은 비우지 않는다**(2026-10-15). 백엔드 교체는 모듈 이미지를 내리지 않으므로 모듈 코드를 가진 되돌리기 명령도 남긴다(`setModuleImageKept`). 패널을 가리키는 명령은 `this` 대신 표지(shared_ptr)로 잡는다.
- **Apply to Prefab 은 같은 씬의 다른 인스턴스에 바로 퍼지고 파일 쓰기와 인스턴스 갱신이 되돌리기 하나다**(2026-10-15, `PrefabCache::updateInstance`). 덮어쓴 값은 옛 원형과 견줘 뽑아 새 원형에 얹는다(`Scene::instantiate` 와 같은 식).
- **지형은 같은 에셋을 다시 읽을 때 저장하지 않은 편집을 넘긴다**(2026-10-15, `TerrainComponent::reloadTerrain`). 다시 읽기 안에서 편집을 들고 건너고(경로가 바뀌면 버림) 플레이 정지 복원은 플레이 스냅샷이 싣는다.
- **메시 모디파이어 셰이딩 미리보기는 GPU 로 못 옮기는 스택이면 CPU 결과 정점 메시로 내려간다 — 와이어만 남기지 않는다**(2026-10-15, `MeshModifierSession::updateShadedPreview`).
- **미리보기 씬(툴 창의 월드)은 씬마다 `FrameRenderer` 인스턴스 하나로 그린다 — 주 렌더러 안의 GPUScene 을 씬 키 맵으로 바꾸지 않는다**(2026-10-15, `FrameRendererScenePreview.cpp`). 주 렌더러의 핫 패스를 그대로 두어 주 씬 그림이 바뀔 여지가 없다(유니티 `PreviewRenderUtility` 와 같음). PSO 캐시는 주 렌더러의 것을 함께 쓰고(창을 다시 열 때마다 엔진 PSO 를 다시 만들던 히치를 없앰) 정점 풀 · 머티리얼 그룹 버퍼는 렌더러마다 따로다 — 정점 풀 공유(`EditorMultiWorld.md` 결정 2)는 미리보기 창이 여럿 열려 메모리가 문제일 때 다시 본다. 미리보기 렌더러는 디바이스에 하나인 GPU 타임스탬프 · 프로파일 구간 · 렌더 타깃 목록을 건드리지 않는다.
- **툴 창의 Undo 는 창마다 스택이고 포커스된 창이 자기 스택을 건다**(2026-10-15, `editor::setFocusedCommandStack`). 오브젝트 Undo 명령은 기록할 때의 씬 키를 기억해 그 씬에서 되돌리며 씬이 사라지면 아무것도 하지 않는다(언리얼 · 유니티는 전역 스택 하나에 대상을 붙임, 계획 3 절).
- **확장 모듈(에디터 플러그인)은 등록 줄 `SW_EDITOR_SUBSYSTEM` 으로 에디터 서브시스템을 기여한다 — 함수 정적 싱글턴을 두지 않는다**(2026-10-14, `EditorExtensionSubsystems`). 확장은 에디터가 뜬 뒤에도 로드 · 언로드되므로 패널과 같은 장치(등록 목록 세대 · 모듈 언로드 직전 `releaseSubsystemsWithin`)로 만들고 내린다. 등록 줄은 UI 쪽 .cpp 에 둘 수 있다.
- **렌더러 안(FrameRenderer 의 PSO 캐시 · 트랜지언트 풀 · 리드백 · 캔버스)도 서브시스템으로 만들지 않는다**(2026-10-14) — RHI 안(5-5)과 같은 이유다. 모듈이 렌더 패스를 등록하는 창구(`G-1`)는 쓰는 모듈이 생길 때 만든다 — 소비자 없이 만들면 검증되지 않은 채 썩는다.
- **버그 리포트는 언리얼 `BugIt` 모양의 엔진 개발 명령이다**(2026-10-10). 폴더 하나(zip 없음)에 info · 스크린샷 · 로그 · 씬 사본 · 재현 명령을 두고 `bugitgo` 는 폴더를 주지 않으면 가장 최근 폴더다. 입력 녹화는 담지 않는다(전역 녹화기가 없음).
- **표시 이름(`DisplayName`)이 없는 프로퍼티는 코드 이름을 다듬어 보인다 — 규칙은 `EditorDisplayNameUtil` 한 곳이고 리플렉션 인스펙터 · 프리팹 오버라이드 목록 · 머티리얼 패널이 같이 쓴다**(2026-10-27). `_boundsRadius` → "Bounds Radius", `bIsVisible` → "Is Visible". 유니티(`ObjectNames.NicifyVariableName`)와 언리얼(`FName::NameToDisplayString`)도 변수 이름을 다듬어 보이는 함수를 에디터 이름표에 쓴다(함수가 있는 것까지 확인, 세부 규칙은 대조하지 않음). 적힌 표시 이름이 늘 이기고, 만든 이름은 번역 키가 아니다(번역 수집은 `SW_LOCTEXT` · 에셋만 읽는다). 옛 이름(`Alias`)은 읽기 키라 이름표에 쓰지 않는다.
- **인스펙터의 "기본값과 다름" 은 컴포넌트 타입마다 만든 기본 인스턴스와 견준다**(2026-10-10, 언리얼 CDO). 이 저장소는 초기값을 생성자에 둬(AGENTS) 리플렉션 메타의 기본값 글이 대부분 비어 있다. 메타 글은 중첩 구조체처럼 인스턴스가 없을 때만 쓴다.
- **환경설정 값은 프로퍼티 글 형식(`formatPropertyText`)의 문자열로 저장한다**(2026-10-10 — 형식마다 JSON 타입을 맞추지 않아도 왕복이 같음). 단축키 키 이름은 낱말(`Comma` · `0`)이고 저장 파일은 `{ "id": [ "주 조합", "보조" ] }` 다. 모듈 창은 매니페스트를 고치고 Build 단추만 두며 다시 시작은 손으로 한다.
- **에디터 폴더는 층이고 틀은 아래 · 구체는 위다**(2026-10-11). 층 경계는 린트가 아니라 빌드 형식이 막는다(2026-10-22, 린트 `CheckEditorLayers` 를 지움): 티어마다 OBJECT 부분 `EditorTier<N>Model` · `EditorTier<N>View` 를 짓고 부분마다 자기 티어보다 위 층의 모든 헤더 자리에 `#error` 껍데기(`<빌드>/generated/sw/EditorLayerStubs/tier<N>`)를 include 자리 맨 앞에 둔다. 위 층 헤더를 include 하면(전이 포함) 컴파일이 멈춘다. 표는 `Scripts/lint/rules/GenerateEditorLayers.toml` 이고 폴더와 어긋나면 configure 가 멈춘다. 커맨드가 패널을 여는 일은 창구 `IEditorPanelHost`, 상태 막대 항목은 등록 줄 `SW_EDITOR_STATUS_BAR_ITEM` 이고 예외는 잎 헤더(`[prelude]`)뿐이다. 모든 매니저를 만드는 조립 파일은 EditorModule 자신(`Source/Editor` 바로 아래)이 가진다.
- **ImGui 를 모르는 층(Common 의 Asset · Commands · Config · Localization · SourceControl · Workspace)은 OBJECT 라이브러리 `EditorModel` 로 짓고 오브젝트를 EditorModule DLL 에 그대로 넣는다**(2026-10-17, `sw_addModulePart`). 정적 라이브러리나 별도 DLL 로 떼지 않는다 — 확장 모듈이 따로 링크하면 정적 상태가 두 벌이 되고 export 가 빠질 수 있다. vcpkg 가 모든 패키지 헤더를 한 include 자리에 두어 imgui.h 를 include 자리로 숨길 수 없으므로 `IMGUI_USER_CONFIG` 에 `#error` 헤더를 주어 imgui.h 를 거치는 include 를 컴파일 오류로 만든다.
- **에디터 컨텍스트 조회는 `editor::getSubsystem<EditorContext>()`(있어야 함, 참조)와 `editor::findSubsystem<EditorContext>()`(없을 수 있음, 포인터) 둘이고 옛 `EditorContext::get()` 은 지웠다**(2026-10-26, `editctx`). `get()` 은 null 을 허용해 널 확인이 붙었고(결함을 가린다) 필수 조회의 부재 보고는 `SW_ASSERT` 라 Release 에서 사라져 널 역참조가 됐다. 판정은 호출 문맥이다: 컨텍스트가 있어야 도는 곳(그리기 · 패널 · 팝업 · 메뉴 · 에디터 UI 전용 명령)은 `getSubsystem`, 없이도 계속하는 정상 경로(컨텍스트 없이 도는 EditorTest, 종료 · 해제 경로, 에디터 없는 호스트에도 등록된 탐침 · 시계 조건, 실패를 `false` 로 알리는 개발 명령, 셀프테스트)는 `findSubsystem`. 부재 보고는 Core 의 `sw::internal::reportMissingRequiredService` 하나로 모아 모든 구성에서 stderr 출력 후 `abort` 한다. 새 `find()`/`require()` 멤버를 만들지 않고 결정 5-3 의 `getSubsystem`/`findSubsystem` 한 어휘를 쓴 이유: `static require()` 는 `CheckServiceAccess` 가 전역 단일체 창구로 막고 같은 조회의 두 번째 철자는 새 코드가 쓰는 길을 가린다. 옛 이름의 재등장은 `CheckServiceAccess` 의 `RetiredWindow` 가 막는다.
- **패널과 커맨드의 에디터 컨텍스트 조회(62 파일 224 곳)는 생성자 · 인자 주입으로 바꾸지 않는다**(2026-10-11). 패널은 레지스트리가 인자 없이 만들고(`createEditorPanel<T>`) 상용 엔진도 에디터 하위 시스템을 전역 창구로 준다(언리얼 `GEditor->GetEditorSubsystem<T>()`, 유니티 `Selection.activeObject`). EditorTest 는 `EditorContext` 를 만들 수 없어 인자로 바꿔도 테스트가 늘지 않는다. 테스트할 판단이 생기면 그 함수만 필요한 서비스 하나를 인자로 받는다.
- **임포터(`Editor/Common/Asset`)를 라이브러리로 떼지 않는다**(2026-10-11). 명령 줄 임포트(`App --import-*` · `--check-*`)는 App 이 에디터 모듈을 인스턴스 없이 로드해 C-ABI 진입점 `importEditorAssets` 를 부르고 쿠킹은 임포트 산출물만 읽으며 전용 서버와 Shipping 은 임포트하지 않는다. 에디터 없는 빌드 팜에서 임포트할 일이 생기면 그때 묶는다.
- **imgui-node-editor 는 vcpkg 내장 포트를 그대로 쓰고 업스트림에 PR 은 내지 않는다**(2026-10-18 · 2026-10-06 사용자 결정). `<exception>` 패치 오버레이는 macOS 때문이었고 macOS 는 지원 대상이 아니다.
- **DPI 150 % 는 대체 테스트로 확인하고 글자 래스터 선명도만 실제 모니터에서 확인한다**(2026-10-06). 남은 확인은 [후보 문서](../plans/Candidates-ui.md) `B-8`.
- **에디터 보강의 결정 열다섯 개(D1 ~ D15)**(2026-10-06, 사용자 지시 "특별한 의도가 없으면 상용 엔진과 비교해 나은 쪽"으로 추천을 정함). 단위는 모두 적용했고 남은 로드맵은 [후보 문서](../plans/Candidates-editor.md) `D3-1` 이다.
  - **확장 지점**(D1 ~ D4): EditorModule 을 SHARED DLL 로 바꾸고 `SW_EDITOR_API` 로 내보낸다. 키트의 에디터 확장은 `Source/GameFramework/PlugIn/Editor/<이름>/` 의 `GF_EditorPlugIn_<이름>`, 게임의 것은 `SWGameEditor`, 매니페스트 종류는 `EditorExtension`(Dev 전용)이다. 등록부만 따로 떼지 않은 이유는 확장이 쓸 위젯 · 선택 · Undo 까지 결국 옮겨야 하기 때문이다. vcpkg imgui 는 정적 라이브러리라 DLL 마다 사본이 생기므로 CMake 가 확장마다 ImGui 컨텍스트 결속 소스를 만든다. 확장의 메뉴와 단축키는 `SW_EDITOR_COMMAND`.
  - **설정**(D5 ~ D7): 환경설정은 `Saved/Editor/EditorPreferences.json` 에 기본값과 다른 값만 두고 섹션은 리플렉션 구조체 하나, 단축키 덮어쓰기는 `Saved/Editor/Shortcuts.json` 이다. 모듈 켜고 끄기는 매니페스트를 고치고 빌드와 재시작을 묻는다(실행 중 켜기 없음).
  - **디버그와 캡처**(D8 ~ D13): assert 무시 대화상자는 대화형 에디터 실행에서만 띄운다(`-unattended` · 시나리오 · 프로파일은 멈춤). GPU 캡처는 네 백엔드를 모두 잡는 RenderDoc in-app API 이고 PIX 는 하지 않는다. 스크린샷 버튼은 PNG, `-gv_screenshot` 은 PPM 이다. Shader Complexity 보기 모드는 하지 않는다(머티리얼 그래프가 없어 의미가 약함). 스레드 미니 타임라인은 프로파일러 패널 안에 두고 깊은 분석은 Tracy 로 한다.
  - **씬 뷰 / 게임 뷰 분리**(V1): 에디터 카메라 뷰(Scene)와 게임 카메라 출력(Game)은 다른 패널이고 재생 단추는 상단 툴바다. 보이는 패널의 뷰만 그리고 엔진에는 게임 뷰를 주 출력으로 · 씬 뷰를 호스트 타깃 추가 뷰로 요청한다(렌더러를 두 번 돌리지 않고 다중 뷰 하나로).
  - **씬 뷰 툴바는 떠 있는 오버레이 바**(2026-10-11, 사용자 요청): 유니티 Overlays 처럼 바마다 끌어 옮기고 붙이고 접고 숨긴다(언리얼의 고정 툴바는 좁은 씬 뷰에서 잘림). 재생 툴바(상단)는 그대로 둔다(도킹 창으로 바꾸는 안은 사용자가 거둬들임).
  - **선택 표시는 경계 상자**(N1): 강조 주황 경계 상자(Godot 3D 선택 상자). 언리얼 · 유니티의 실루엣 외곽선은 선택 오브젝트만의 스텐실 · id 버퍼가 네 백엔드에 다 있어야 해 미뤘다.

Unreal 의 알림도 하이퍼링크 단추를 알림 항목이 가진다. 단추가 있는 토스트만 마우스를 받고 나머지는 입력을 통과시킨다. 단언 대화상자는 OS MessageBox 라 자동 실행에서 걸리지 않아 시나리오 대상이 아니다. 후보 문서의 "눈으로 · 수동" 문구를 시나리오와 대조했으나 나머지는 GPU 화면 판독 · 외부 앱(VS · WSL · 4 백엔드 PC)이라 자동 단언으로 바꿀 수 없어 남긴다.
- **계층 창의 필터는 `EditorListFilter::isActive` 하나로 켜고 끄며, 공백뿐인 글은 꺼진 필터다**(2026-10-27, 감사 SB E1). 전에는 루트가 이 술어를, 노드가 "빈 문자열인가" 를 따로 봐서 공백만 친 필터가 루트는 모두 보이고 노드는 이름 매칭으로 걸렀다. 행 모델(루트 순서 · 걸린 오브젝트 집합)을 구조 세대 · 태그 세대 · 필터 글이 바뀔 때만 짓게 하며 술어를 하나로 모았다(유니티 Hierarchy · 언리얼 아웃라이너도 공백 검색은 전체를 보인다).
