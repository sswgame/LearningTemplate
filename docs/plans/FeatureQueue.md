# 남은 기능 대기열

> 상태: 참고 · 선행: 없음 · 영역: gameplay · 옛번호: D4-9 · 진행: 해당없음

아직 착수하지 않은 큰 기능을 크기순으로 둔 대기열이다. 착수하는 것부터 이름 있는 계획 문서로 떼어 내고 여기서 지운다. **2D · 3D 에 다 쓰이는 기능은 공통 코어로** 한다(사용자 지시).
다른 문서에 있는 것은 다시 적지 않는다: 메시 LOD · PSO 미리 만들기 · 밉 스트리밍은 [PreloadAndLod](PreloadAndLod.md).

## 중간(M)

- 도구: 대역폭 프로파일러 · 게임플레이 디버거 · 모듈 패키지 관리(옛 D3-8) · 에셋 DCC 내보내기 · 비주얼 로거의 에디터 프레임 슬라이더 패널.
- 렌더링: HZB 가림 컬링의 밉 사슬 · 두 단계 컬링 · SSR · 시간 누적 업스케일러 · HDR 출력 · 데칼 · 2D 스켈레탈.
- 학습용: 장르 시작 템플릿 · 튜토리얼 · API 문서.

## 큼(L)

- 시스템: 제약 · 파티클/VFX · 에셋 레지스트리 · DDC · 증분 쿠킹 · 전술 AI · 대규모 좌표.
- 렌더링: 볼류메트릭 안개/빛/구름 · 캐릭터 셰이딩 · GI/반사 프로브.
- 저작: 월드 편집 도구 · 모션 캡처 공정 · PCG 저작 그래프.
- 서비스: 플랫폼 서비스 · 패치/DLC · 모드/UGC.

## 아주 큼(XL)

- 비주얼 스크립팅 · 월드 파티션/스트리밍/HLOD · 음성 채팅(온라인 구성은 옛 D7-5).
