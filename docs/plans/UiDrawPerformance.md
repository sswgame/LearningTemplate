# 런타임 UI 그리기 성능의 남은 것

> 상태: 설계 · 선행: 없음 · 영역: ui · 옛번호: D6-6 · 진행: 0/2

목표(`GT.UI` p50 0.3 ms) 안이다(측정값과 걷기 분해는 [검증과 측정](../08_Verification.md) 2절 "런타임 UI 벤치"). 더 줄일 후보 둘을 단위로 둔다. 도입 여부는 `Engine/UI/README.md` "성능" 절의 세 측정(멈춘 화면 · 일부만 바뀜 · `-gv_benchUiOpacityPulse`)과 그 절의 도입 기준으로 정한다.

## 1. 단위

| 단위 | 내용 | 선행 |
|---|---|---|
| U1 | 패널마다 하위 출력 캐시(Slate Invalidation Panel) | 없음 |
| U2 | 조상의 `kTransform` 이면 자손까지 다시 칠하는 그림 캐시의 변환을 캐시 밖에서 곱하기 | 없음 |

두 단위 모두 세 측정에서 이득이 기준에 닿지 않으면 하지 않고 이 문서를 `끝` 으로 닫는다. 창 크기 바꿈(전체 재배치) 한 프레임 · 첫 프레임 글리프 래스터화가 몇 프레임에 퍼지는지는 표 밖이다(워밍업 60 프레임이 버린다 — 글리프 쪽은 [GlyphRasterizationHitch](GlyphRasterizationHitch.md)).
