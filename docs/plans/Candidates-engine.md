## 조건부

### MetalMobileConsole
제목: macOS(Metal RHI) · 모바일 · 콘솔 백엔드
왜 필요한가: RHI 는 DX12 · Vulkan · DX11 뿐이다. 콘솔은 SDK 계약이 필요하다.
착수 조건: 해당 플랫폼으로 내는 게임이 생길 때.
남은 첫 일: 백엔드 하나를 골라 RHI 인터페이스 구현을 시작한다.
