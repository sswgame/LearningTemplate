# 메시 모디파이어 미리보기 비용

> 상태: 측정대기 · 선행: 없음 · 영역: editor · 옛번호: D3-10 · 진행: 0/3

`GF_EditorPlugIn_MeshModifiers` 는 56 id 를 등록했습니다. 구조 · 추가 방법 · 알려진 근사는 [모듈 README](../../Source/GameFramework/PlugIn/Editor/MeshModifiers/README.md), 구조는 같은 문서의 "셰이딩 미리보기" 에 있습니다.
남은 것은 측정이 먼저인 비용 문제와 아직 눈으로 보지 않은 캡처입니다.

## 1. 단위

| 단위 | 내용 | 선행 |
|---|---|---|
| MM1 | 패널 캡처 확인: 시나리오 `editor.meshmodifiers` 가 찍는 `meshmodifiers/panel.png` · `gizmo.png` · `nested.png` 를 돌려 눈으로 본다 | 없음 |
| MM2 | 셰이딩 미리보기 비용 측정: 큰 메시(10 만 정점 이상)에서 매개변수 끌기 · 시간 재생 중 프레임 시간을 Release 로 잰다(매개변수가 바뀌면 고른 모디파이어부터 CPU 로 한 번 돌고, CPU 로 내려간 스택은 바뀔 때마다 정점 버퍼를 새로 만든다) | MM1 |
| MM3 | MM2 가 크면 엔진 `Mesh` 에 정점 갱신 API(렌더 스레드와 이중 버퍼)를 더해 매번 새로 만들지 않게 한다. 작으면 취소 | MM2 |

## 2. 받아들인 것

- 텍스처 표본기는 8 비트 원본도 float4 로 보관한다(4 배). 캐시 상한(512 MB, 1 초 넘게 안 쓴 것부터 내림)이 이미 있어 이 크기를 받아들인다. 파일 변경 감지는 1 초 지연이다.

## 3. 함정

clang-format 20.1.8 로 줄 길이를 맞출 것(이 PC 는 21.1.1).
