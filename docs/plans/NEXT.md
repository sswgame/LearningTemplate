## 지금 상태 (2026-10-10)

- main 에 들어간 것: 3 차(가상 입력 · 자동화 시나리오 · 빙의 · 탑승), 4 차(런타임 UI 전부 + 원시 장치 조회 → 입력 맵 액션), 5 차 a(문서 분리 · 다시 쓰기 · 작업 방식), 5 차 b 의 대부분.

## 5 차 b 에서 남은 것

백로그와 대조해 확정한 뒤 시작합니다(커밋 제목으로만 가려서, 일부는 이미 들어갔을 수 있습니다).

- 의존성 기준선 올리기: openssl 3.6.5 · imgui 1.92.9 · meshoptimizer 1.3 · mimalloc 3.5.3 · vulkan 1.4.363 · tracy 0.14.1(+viewer) · RTM 2.3.1. OpenSSL 4 · glad2 · DXC 최신은 올리지 않습니다. `deps-outdated` 스크립트도 함께.
  vcpkg 를 바꿀 때는 다른 워크트리 빌드가 없을 때 main 에서 먼저 합니다.
- 옵션 창이 720p × 배율 1.5 에서 넘치는 문제.
- 런타임 UI 그리기 성능: 1.6 ms 를 0.3 ms 목표로(`Source/Engine/UI/README.md` "성능").
- 고정 픽셀 46 곳이 UI 배율을 따르지 않는 문제(패널 점검 D24), 깨끗하게 띄울 때마다 남는 경고 2 건(D25).
- 에디터 리소스: 못 읽은 텍스처 · 머티리얼을 마젠타 체커로 보이기(R6), 앱 · 창 아이콘(R8)이 들어갔는지 확인. 프로토타입 격자 머티리얼 3 개(R7).
- 백로그 두 줄: 월드 공간 UI 의 GPU 경로, 글리프 SDF 컴퓨트.
- 에디터 결함 중 원인을 못 가른 것(D2 · D4 · D21 · D26)이 실행으로 확인됐는지.
