# 문서 줄이기

1. 큰 문서는 `py -3 -m Scripts doc <파일>` 목차 → `--section`. 통째 읽기는 훅이 막는다.
2. **지운다**: 끝난 일의 경과 · 일지, 되돌린 시도의 긴 서술(기각 이유 한 줄만), 일화 · 수치 나열, 같은 말의 반복, 다른 문서에 이미 있는 재서술(정본 링크 한 줄), 코드를 읽으면 아는 설명, 낡은 상태 표.
   **더 깎는 기준**(1차에서 목표에 못 닿았을 때): 규칙 · 함정마다 "이 줄을 지우면 누가 어떤 잘못을 하는가"를 묻고 답이 없으면 지운다. 린트 게이트 · 형식(API · 타입)이 이미 막는 함정은 문서에서 뺀다(게이트 이름 한 줄만). 측정값은 대표값 하나만 두고 날짜 · 해시 · 전후 표는 뺀다. 파일 · 함수 나열 표는 코드를 가리키는 한 줄로 바꾼다. 같은 규칙이 둘 이상의 문서에 있으면 정본 하나만 남긴다.
3. **보존한다**: 지금 유효한 규칙 · 명령 · 수치 · 함정, 결정 한 줄과 이유, 기각 기록, 사용자 결정, 절 제목 · 번호.
4. **고치기 전에** `grep -rn "<파일 이름>" --include=*.md --include=*.py --include=*.json --include=*.h --include=*.cpp .` 로 참조를 확인하고 가리키는 앵커는 바꾸지 않는다. 생성물(스크립트가 만드는 md)은 손대지 않는다.
5. 끝난 계획 문서 전체는 지우지 말고 삭제 후보로 보고한다.
6. 쌓는 모양(일지 절을 계속 추가)이 원인이면 문서만 줄이지 말고 덮어쓰기 · 크기 게이트로 그 모양을 막는다.
