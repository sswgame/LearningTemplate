# humanizer

글을 다 쓴 뒤 아래 목록으로 한 번 훑고 걸린 곳만 고친다. 뜻 · 사실(식별자 · sha · 날짜 · 수치)은 그대로 두고 표현만 바꾼다.

## 지울 버릇

| 버릇 | 고친 꼴 |
| --- | --- |
| 습관적인 대비 "X 가 아니라 Y 다" | 대비가 정말 정보일 때만. 아니면 "Y 다" |
| 줄표(—)로 문장 잇기를 되풀이 | 문장을 끊거나 괄호 · 쉼표. 한 문장에 줄표 하나까지 |
| 억지 셋 늘어놓기("빠르고, 단순하고, 안전하다") | 실제로 있는 만큼만 |
| 부풀린 말("강력한", "완벽히", "핵심적인", "획기적") · 광고 투 | 지운다. 수치나 사실로 바꾼다 |
| 무대 깔기 서두("결론:", "핵심은", "요약하면") | 바로 본론 |
| 한 줄 맺음말("이로써 …가 보장된다") | 지운다 |
| 같은 말 되풀이 · 군더더기 부사("실제로", "명확하게", "단순히") | 한 번만 |
| 굵은 머리표 · 장식 목록 | 평문 문장 |
| 코드가 이미 말하는 것을 다시 말하는 주석 | 지우고, 이유(why)만 남긴다 |
| 이유 없는 이력 이야기("예전에는 …였다, 고쳤다") | 지운다. 이유를 주면 그 이유만 남긴다 |

## 이 저장소에서 더 지킬 것

- 한국어로 쓰고, 지어낸 말 대신 업계 용어(언리얼 · 유니티 · Godot 이름)를 쓴다.
- 커밋 메시지 꼴(첫 줄 요약 + 원인: → 조치: → 결과:)은 그대로다. 각 줄 안의 표현만 다듬는다.
- 주석을 다듬을 때 코드 · 문자열 리터럴 · 로그 글 · PROPERTY 인자는 건드리지 않는다.
