# 작업자 지시문

**0. 새로 띄우기 전에 재사용부터(에이전트 수도 비용).** `ListAgents` 로 본다.
- 같은 영역을 하던 작업자 → 그에게 SendMessage 로 잇는다(브랜치도 안 늘어난다).
- 없으면 **같은 모델이고 레벨이 필요한 것 이상인, 일이 끝나 놀고 있는 작업자**(medium 일은 놀고 있는 high 에게도 맡길 수 있다)에게 새 일을 잇는다(워크트리는 새 이름으로 만들게 한다).
- 둘 다 없을 때만 새로 띄운다. 동시에 8개 안팎을 넘기지 않는다. 찾기만 하는 일은 `scout`.
보고를 받은 그 턴에 "같은 결함 후보"도 이 순서로 바로 맡긴다(나열만 하고 넘어가지 않는다).

지시문에 넣을 것(빠뜨리면 규칙 위반):
1. **워크트리**: `py -3 -m Scripts worktree-make <이름> --base <브랜치>` (isolation 쓰지 않는다).
2. **첫 단계 재측정**: 계획 문서 상태를 믿지 않고 `plans --file`, `RunFunctionSize.py` 등으로 남은 단위가 코드 일인지 확인. 없으면 보고하고 멈춘다.
3. **읽을 문서 · 절**: 이름으로(`Scripts doc <파일> --section <제목>`), 규칙은 `docs/agents/` 의 해당 파일.
4. **끝낼 때 고칠 문서**: 고치는 곳과 고치지 않는 곳(NEXT.md · StatusBoard 는 통합 몫).
5. **범위 끝**: 린트 → `syntax-check` → 커밋 → 멈춤. 빌드 · 링크 · 테스트 · 실행 · 병합 · push 금지.
6. **보고**: 한국어, 파일별 결과와 "같은 결함이 다른 곳에 있을 가능성" 한 줄.

모델은 일에 맞는 가장 싼 것으로 고르고 `model` · `effort` 를 지정한 뒤 사용자에게 표(담당 | 종류 | 모델 | 레벨 | 일)로 알린다.
