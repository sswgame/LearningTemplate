# Box2D 백엔드 — 2D 물리

`IPhysicsScene2D` 를 Box2D v3 로 구현한 폴더입니다. `<box2d/...>` 헤더를 include 할 수 있는 곳은 이 폴더뿐입니다(`CheckThirdPartyIsolation.py`).
물리를 쓰는 방법과 규칙은 [Physics](../README.md)에 있습니다. 이 문서는 Box2D 백엔드만의 사정을 다룹니다.

| 파일 | 내용 |
|---|---|
| `Box2DPhysicsBackend.h` | 씬 생성. 전역 상태가 없고, Box2D 헤더를 include 하지 않습니다 |
| `Box2DPhysicsScene` | 바디, 셰이프(사슬 포함), 레이어 필터, 쌍 예외, 이벤트 |
| `Box2DPhysicsSceneQuery.cpp` | 관절, 캐릭터 무버, 레이 캐스트, 셰이프 캐스트, 겹침 질의 |
| `Box2DUtil.h` | 수학 타입 변환, 사용자 값, 셰이프 id 키 |
| `Box2DWorkerPool` | 씬마다 붙는 전용 워커(`_workerCount2D` 가 2 이상일 때) |

엔진 레이어는 Box2D 의 범주 비트로 바꾸고, 바디 쌍의 충돌 예외는 필터 관절로 구현합니다. 이벤트는 접촉, 센서, 부딪힘 이벤트를 모읍니다.
레이 캐스트 결과의 재질 이름은 셰이프의 `userMaterialId` 에 넣어 둔 재질 번호로 찾습니다.

**스레드.** 월드는 기본으로 한 스레드로 돕니다. Box2D 의 솔버 워커들은 서로를 바쁘게 기다리는 구조라, 공유 작업 풀에 넘기면 교착 상태가 될 수 있습니다.
바디가 수천이면 `physicssettings.xml` 의 `_workerCount2D` 를 2 이상으로 둡니다. 그러면 씬마다 Box2D 일만 하는 전용 스레드(`Box2DWorkerPool`)를 붙입니다.

- **소유.** 월드는 스텝을 부르는 게임 스레드가 가집니다. 워커는 `b2World_Step` 안에서 Box2D 가 넣은 태스크 조각만 실행하고, 엔진 코드나 씬 함수를 부르지 않습니다.
  스텝을 부른 스레드는 일꾼 0 번이고, 기다리는 동안 대기열을 함께 비웁니다. 전용 스레드는 1 번부터입니다.
- **교착하지 않는 이유.** 대기열은 넣은 순서대로 꺼냅니다. 솔버의 0 번 태스크가 먼저 들어가 먼저 꺼내지고, 0 번은 다른 태스크 없이도 모든 블록을 끝낼 수 있습니다.
- **잠금 순서.** 풀의 잠금은 잎 잠금입니다. 대기열을 고치는 동안만 쥐고, 쥔 채로 Box2D 콜백이나 다른 잠금을 부르지 않습니다.
- **결정성.** Box2D v3 는 일을 고정 블록으로 나누므로 워커 수와 관계없이 결과가 같습니다(`PhysicsScene2DTest.StepIsDeterministicAcrossWorkerCounts` 가 비트까지 비교).
- **효과 재기.** `PhysicsBenchTest.Box2DStepByWorkerCount` 가 동적 바디 3000 개 더미의 스텝 시간을 일꾼 수 1, 2, 4, 8 로 잽니다. Release 로 읽습니다.
  유니티의 Physics2D 다중 스레드 옵션에 해당하며, 바디가 수백이면 깨우는 비용 때문에 한 스레드가 더 빠를 수 있습니다.

**관절.** 용접, 회전, 거리, 직선 관절을 지원하고, 원뿔(Cone) 관절은 오류입니다. 월드에 붙는 관절은 씬이 가지고 있는 원점의 정적 바디에 붙입니다. 위치 모터는 목표 각이나 거리로 당기는 관절 스프링입니다.

**충격량.** 시작 이벤트의 충격량은 부딪힘 이벤트의 다가온 속도 × 유효 질량 × (1 + 반발)입니다. 유지 이벤트는 마지막 서브 스텝의 `normalImpulse` 에 서브 스텝 수를 곱합니다.
`totalNormalImpulse` 는 이완 반복까지 더한 값이라 약 두 배이므로 쓰지 않습니다.

**캐릭터 무버.** `b2World_CollideMover`, `b2SolvePlanes`, `b2World_CastMover` 를 최대 다섯 번 되풀이하고, 캡슐을 조금 내려 디딤 바닥을 찾습니다.
