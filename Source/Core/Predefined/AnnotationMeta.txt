# =============================================================================
# AnnotationMeta — REFLECT / ENUM / ENUMERATOR / PROPERTY / FUNCTION 토큰 → canonical 필드
# =============================================================================
# [SCOPE]
#   kind.필드이름 = 별칭, 별칭2
#
# kinds (토큰 철자는 PredefinedAnnotationKind.xxx 와 동일):
#   flag     단독 토큰 `X` 와 `X=true` 를 **함께** 등록 → bool 필드
#   bool     `X=value` 만 등록 → bool (true/1/True). 단독 토큰을 받지 않을 때만 쓴다.
#   string   key=value → 문자열 필드
#   float    key=value → float (Min/Max 범위)
#   netrole  단독 토큰 → FunctionNetRole (PredefinedFunctionNetRole.xxx)
#   count    key=value → 1 이상의 정수 또는 C++ 정수 상수 이름 (MaxCount, 이름은 생성기가 값으로 푼다)
#
# flag 한 줄이 두 형태(단독 토큰 · `X = true`)를 함께 맡는다. 두 형태를 따로 적지 말 것 — 한쪽이 빠지면
# `PROPERTY( AssetPath = true )` 같은 것이 경고 한 줄 없이 버려지고, 별칭도 한쪽만 늘어나는데 눈에 보이지 않는다.
#
# 별칭만 추가할 때는 여기만 고치면 된다.
# 새 *필드*를 만들면 PredefinedAnnotationField.xxx 에도 한 줄이 필요하다.
# =============================================================================
